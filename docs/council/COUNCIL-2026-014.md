- **Directive ID**: `COUNCIL-2026-014` (`DIR-2026-UI-STANDARD-001`)

- **Status**: `RATIFIED`

## I. Executive Summary

Following the Fleet UI Experience, Typography, Color & Design System Audit (`COUNCIL-UI-AUDIT-2026-11`), the Council formally ratifies a single, unified **ChurchCore Design System Standard** across all 7 software packages.

Previously, individual packages exhibited typography and palette drift:
- Four competing primary sans-serif declarations (`Inter`, `Plus Jakarta Sans`, `Aptos`, and `Outfit`) and three different font-loading mechanisms (`next/font/local`, `next/font/google`, and raw CSS `<link>` tags).
- `ChurchCore Academy` operated an isolated monochrome blurple palette (`Nocturne`: `#161826` canvas / `#232532` surface / `#9184d9` accent) with non-standard fractional font sizes (`0.68rem`, `0.78rem`, `0.82rem`).
- `ChurchCore Care` defaulted to `defaultColorScheme="auto"` (`#f6f8fc` light mode first) and relied on OS-installed `Inter` without bundling self-hosted `.woff2` font files.

This directive establishes 100% fleet standardization on **ADR 0026 + ADR 0038**.

## II. Ratified Technical Requirements

### `REQ-014-01`: Self-Hosted Variable Typography Standard (`next/font/local`)
Every ChurchCore Next.js application MUST bundle and load the three canonical variable `.woff2` font families from local repository storage (`app/fonts/` or `src/app/fonts/`) via `next/font/local` with `display: "swap"`:
1. **Primary UI Sans (`--font-inter` / `--font-sans`)**: `inter-latin-var.woff2` (`Inter`, variable weight `100 900`, SIL OFL 1.1).
2. **Editorial & Liturgical Serif (`--font-fraunces` / `--font-serif`)**: `fraunces-latin-var.woff2` (`Fraunces`, variable weight `100 900`, SIL OFL 1.1).
3. **Technical & Audit Monospace (`--font-geist-mono` / `--font-mono`)**: `geist-mono-latin-var.woff2` (`Geist Mono`, variable weight `100 900`, SIL OFL 1.1).

Runtime dependence on `fonts.googleapis.com` is eliminated so production builds, air-gapped CI runners, and Sunday morning church networks never stall or shift layout waiting on external font CDNs.

### `REQ-014-02`: Dark-First Slate/Indigo Surface Hierarchy & Print Parity
All operational applications MUST share the canonical Dark-First Slate/Indigo token hierarchy:
- **Canvas Background (`--background` / `--sis-bg-canvas` / `--bg`)**: `#020617` (`Slate-950`)
- **Elevated Card Surface (`--card` / `--sis-surface` / `--surface`)**: `#0f172a` (`Slate-900`)
- **Muted / Input / Hover Surface (`--muted` / `--surface-card-muted` / `--surface-muted`)**: `#1e293b` (`Slate-800`)
- **Hairline Border (`--border` / `--sis-border` / `--line`)**: `#1e293b` (`Slate-800`) / `#334155` (`Slate-700` interactive boundary)
- **Primary Brand Accent (`--primary` / `--sis-primary` / `--brand`)**: `#4f46e5` (`Indigo-600` button fill) / `#6366f1` (`Indigo-500` ring & hover) / `#818cf8` (`Indigo-400` high-contrast dark text accent)
- **Secondary Warm / Liturgical Accent (`--warning` / `--sis-warning`)**: `#f59e0b` (`Amber-500`) / `#fbbf24` (`Amber-400`)
- **Primary Text (`--foreground` / `--sis-text-primary` / `--text`)**: `#f8fafc` (`Slate-50`)
- **Secondary / Muted Text (`--muted-foreground` / `--sis-text-secondary` / `--text-soft`)**: `#cbd5e1` (`Slate-300`) / `#94a3b8` (`Slate-400`), meeting WCAG AAA `>= 7.0:1` where required by `REQ-002-02`
- **Print-Safe Overrides (`@media print`)**: All dark-first surfaces MUST reset to `#ffffff` paper canvas and `#111827` / `#111111` ink when printing certificates, transcripts, financial statements, or security badges.

### `REQ-014-03`: Standardized 6-Step Rem Typography Scale & Touch Target Floor
All stylesheets and component libraries MUST normalize onto the 6-step `rem` typography scale:
- **Micro / Badge / Eyebrow (`text-xs`)**: `0.75rem` (`12px`), `line-height: 1rem`
- **Dense Table / Nav / Form Control (`text-sm`)**: `0.875rem` (`14px`), `line-height: 1.25rem`
- **Default Body Copy (`text-base`)**: `1rem` (`16px`), `line-height: 1.5rem`, `letter-spacing: -0.011em`
- **Card / Panel Heading (`text-lg` / `text-xl`)**: `1.125rem`–`1.25rem` (`18px`–`20px`), `font-weight: 600–700`
- **Section Heading (`text-2xl`)**: `1.5rem` (`24px`), `font-weight: 700`, `letter-spacing: -0.022em`
- **Page / Hero Display (`text-3xl+`)**: `1.875rem`–`2.25rem` (`30px`–`36px`), `font-weight: 700–800`, `letter-spacing: -0.025em`
- **Touch Target Floor**: Interactive controls on mobile/member/student flows MUST maintain a minimum `2.75rem × 2.75rem` (`44×44 CSS px`) tap target (`WCAG 2.5.5` / Apple HIG).

### `REQ-014-04`: Automated Contrast & Design Token Contract Verification
Every package's automated test suite MUST verify design-system token integrity and WCAG contrast ratios (`REQ-002-02` / `ADR 0026` / `ADR 0038`) without regressions.
